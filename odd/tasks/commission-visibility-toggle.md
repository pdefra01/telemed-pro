# Commission visibility toggle
Objective: an admin setting decides whether advisors and supervisors see commissions; when off they see only their productivity.
Branch: feat/commercial-crm-followups (on top of feat/commercial-crm-commissions, #103). Delivery: ask-on-risk. Runner: `npx vitest run`, `supabase test db --local`.

## Specs
- S1 "podemos dejarlo en solo mostrar la productivdad sin mostrar nada de comisiones (algun interruptor en Configuracion que prenda y apague mostrar esta info a los asesores)". An admin switch in Configuración (OCCSettings) turns commission visibility on and off.
- S2 The switch applies to "ambos": advisors and supervisors. When off, an advisor does not see the "Comisiones" menu, screen, dashboard KPI or the link text promising commissions; a supervisor does not see "Comisiones del equipo". Productivity (sales, confirmed, pending, links) stays visible. The admin always sees everything.
- S3 Enforced in the database, not only hidden in the UI: when off, an advisor or supervisor reads no rows from advisor_commissions, commission_liquidations, advisor_commission_summary() or advisor_commission_list(). Commission generation and liquidation keep working unchanged.
- S4 Default (assumption): off, matching "dejarlo en solo mostrar la productividad". Stored in system_settings key `commission_visibility` as `{"visible": boolean}`; a missing or malformed value means off.
